# ElasEmpreendem Aiuaba

**A Feira da Mulher Empreendedora de Aiuaba, aberta o ano inteiro.**

👉 **Veja a página aqui:** https://rafa-crypt0.github.io/elasempreendem-aiuaba/

Esta é a primeira versão da página de apresentação do nosso projeto da disciplina Projeto Integrado I. Ela mostra como seria a plataforma, mas ainda é um modelo: os botões e o formulário de cadastro são só ilustrativos.

## Como ajudar a avaliar

1. Abra o link acima, de preferência **pelo celular**, que é como as empreendedoras vão usar.
2. Role a página até o fim e observe os textos, as cores e a organização.
3. Mande sua opinião no grupo do WhatsApp da equipe. Algumas perguntas para guiar:
   - Os textos estão claros e fáceis de entender?
   - Falta alguma informação sobre a feira ou sobre Aiuaba?
   - O que você mudaria no visual?

Não precisa saber programar para ajudar. Sua opinião como usuário é o que mais importa nesta fase.

## O que a página apresenta

- **Vitrine:** um perfil para cada negócio, com fotos dos produtos e botão direto para o WhatsApp.
- **Aprenda:** aulas curtas sobre preço, controle do caixa, MEI e redes sociais.
- **Ferramentas:** calculadora de preço de venda e controle de entradas e saídas.
- **Rede:** grupo das empreendedoras de Aiuaba, da sede e da zona rural.
- **Oportunidades:** datas da feira, cursos, editais e linhas de crédito num só lugar.

## Para quem programa

Esta página é um **protótipo exportado de uma ferramenta de design**, não o código final. Os estilos estão dentro do HTML (`style="…"`) e guardam os valores do design: cores, fontes, espaçamentos e layout.

**Arquivos:**

- `index.html`: redireciona para a página principal.
- `Main.dc.html`: a página em si.
- `support.js` e a pasta `vendor/`: o código que monta a página no navegador (React minificado). Não precisam ser editados.

**Para abrir no computador:** rode `python -m http.server` dentro da pasta e acesse `http://localhost:8000`. Alguns navegadores não abrem a página com dois cliques no arquivo.
